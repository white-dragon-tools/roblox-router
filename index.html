Roblox Router

快速跳转到 Roblox Player 或 Studio

使用方法

🎮 启动游戏 (Player)

#/play/<placeId>

示例: #/play/6900305353

🛠️ 编辑游戏 (Studio)

#/studio/<placeId>?universeId=<universeId>

示例: #/studio/6900305353?universeId=2414851778

支持的参数

参数 说明 适用
launchData 自定义启动数据 Player
gameInstanceId 特定服务器实例 ID Player
universeId 游戏的 Universe ID Studio
